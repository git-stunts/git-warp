## Release proposition

Replace production full-state replay/materialization contracts with indexed retained roots, bounded causal reduction and root commitments. Add typed recursive graph references with lawful ownership, cycle-safe traversal and retention; migrate real repositories through the same bounded paths. Large graphs and assets become process-memory-bounded rather than merely generator-shaped.

**Version boundary:** MAJOR: retained substrate/commitment and migration boundaries change. Keep legacy decoding in migration scripts, preserve source authority until verified promotion, and provide an explicit upgrade/recovery contract.

## Capability boundary

### Before this release

The v20 line provides safer producers, public byte attachments, and bounded observations, but production retained-state, replay, hash/proof, or migration paths can still require complete graph values. Streaming physical CAS chunks does not bound memory if a consumer collects one logical value before decoding it.

The [earlier incident/design record](../streaming-indexed-recursive-warp.md) documents a 23,995,927-byte logical replay-basis value hitting a 5 MiB decoder boundary. Its historical v20 release target is superseded by this milestone; its old source anchors are evidence, not a fresh audit of current main.

### After this release

Retained manifests and bounded ordinal address pages back selection, causal reduction, root commitments, and public consumers. Supported production operations use bounded pages/streams or explicit external-memory workspace instead of requiring a resident complete graph.

Typed graph references distinguish finite structural ownership from external/live links. Traversal handles cycles and budgets; retention and diagnostics preserve the correct descendants. Existing repositories migrate through those same production paths with verified promotion and recovery. Public bulk ingestion uses bounded atomic batches and backpressured receipts.

### Still out of reach

This does not promise constant total work, bounded disk usage independent of graph size, an atomic transaction over an unbounded stream, durable automatic bulk retry, or witnessed braid admission/unmerge. Scanning a whole graph may still be necessary; process memory must be governed by declared budgets rather than its total cardinality.

## Exit invariants

- No supported production operation requires a complete in-memory graph or full-state codec. Legacy decoding remains isolated in migration scripts ([#814](https://github.com/git-stunts/git-warp/issues/814)).
- Address pages, shards, queues, concurrency, and external workspace have explicit validated budgets; generators cannot hide graph-wide maps ([#815](https://github.com/git-stunts/git-warp/issues/815)/[#816](https://github.com/git-stunts/git-warp/issues/816)/[#817](https://github.com/git-stunts/git-warp/issues/817)).
- Root commitments and readings preserve causal meaning across reopen, checkpoint, cancellation, comparison, BTR, export, and diagnostics.
- [#192](https://github.com/git-stunts/git-warp/issues/192) owns the semantic indexed-property boundary; [#228](https://github.com/git-stunts/git-warp/issues/228) removes the obsolete bridge; [#248](https://github.com/git-stunts/git-warp/issues/248) migrates runtime/controller consumers; [#814](https://github.com/git-stunts/git-warp/issues/814) performs final contract/codec removal.
- Recursive ownership follows [#903](https://github.com/git-stunts/git-warp/issues/903). Traversal reachability does not imply owned retention; shared children, external cycles, and live locators have explicit behavior ([#819](https://github.com/git-stunts/git-warp/issues/819)/[#820](https://github.com/git-stunts/git-warp/issues/820)/[#821](https://github.com/git-stunts/git-warp/issues/821)).
- Source refs remain authoritative until migration verification and compare-and-swap promotion succeed; refusal/cancellation preserves recovery ([#811](https://github.com/git-stunts/git-warp/issues/811)/[#822](https://github.com/git-stunts/git-warp/issues/822)).
- A bulk batch is atomic, the whole stream is not. Bounded pulls and receipts distinguish committed prefixes from refused/unconsumed suffixes ([#917](https://github.com/git-stunts/git-warp/issues/917)).
- Every claimed production path passes the fixed heap/RSS and correctness matrix in [#823](https://github.com/git-stunts/git-warp/issues/823); increasing the old decoder ceiling is not a substitute.

### Discovery

Thirty-one cards require current-owner and contract reconciliation. The inventory identifies them individually. Prioritize discovery that could invalidate the proposition: full-adjacency sorting ([#388](https://github.com/git-stunts/git-warp/issues/388)), traversal collection ([#457](https://github.com/git-stunts/git-warp/issues/457)), cache/buffer behavior ([#456](https://github.com/git-stunts/git-warp/issues/456)), builder geometry ([#375](https://github.com/git-stunts/git-warp/issues/375)/[#455](https://github.com/git-stunts/git-warp/issues/455)), and decoder limits ([#476](https://github.com/git-stunts/git-warp/issues/476)). Existing generic CBOR limits do not prove every new boundary is safe, but neither does [#815](https://github.com/git-stunts/git-warp/issues/815) automatically require a speculative decoder rewrite.

For each discovery, record whether the behavior is already satisfied, superseded, outside the supported production contract, or a newly required executable fix. Do not declare the global invariant complete while an unresolved candidate may hide an unbounded path.

### Explicitly out of scope

Braid collapse and unmerge; undocumented retained-root compatibility aliases; hidden whole-graph collectors; restoring deleted legacy bridge implementations merely to delete them again; whole-stream transactions; unrelated ecosystem adoption. A production operation excluded from support must have an explicit supported/refused contract and consumer documentation, not just be omitted from [#823](https://github.com/git-stunts/git-warp/issues/823).
